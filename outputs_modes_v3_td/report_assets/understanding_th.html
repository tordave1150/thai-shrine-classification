อธิบายผลการทดลอง Thai Shrine Classifier

เอกสารนี้สร้างจาก logs ภายใต้ outputs_modes_v3_td เท่านั้น งานที่บันทึกเสร็จ: tuning สำเร็จ 75/75 unique trials; final 75/75 unique seeds.

ข้อมูลและ preprocessing

ใช้ภาพ 560 ภาพใน 4 classes และ canonical grouped split เดิม train 390 / validation 85 / test 85 จาก 550 groups. URL ไม่ทราบ 112 ภาพ. แปลงภาพเป็น RGB, EXIF orientation, resize โดยรักษาสัดส่วนลง canvas 224 × 224 สี neutral RGB (124,116,104), แล้ว normalize แบบ ImageNet. Augmentation ใช้ train เท่านั้น.

คำถามที่ทดลอง

เปรียบเทียบ CNN 5 แบบและนโยบายการฝึก 3 แบบ โดยให้แต่ละคู่สุ่มค้น learning rate, weight decay, optimizer และ batch size จาก validation ของตัวเอง ดังนั้น Full, Frozen และ Partial มี hyperparameters ชนะของตัวเอง. ใช้ ImageNet weights, class-weighted cross entropy, AdamW/Adam/SGD และ ReduceLROnPlateau. Frozen ฝึก classifier; Partial เปิด semantic final stage กับ classifier; Full ฝึก backbone ทั้งหมด.

ขั้นตอนและการอ่านผล

  1. ตรวจไฟล์/provenance และใช้ grouped split เดิม 70/15/15 เพื่อกัน duplicate group ข้าม split
  2. สุ่ม 5 configurations ต่อ architecture × mode ด้วย seed 42; trials ใช้ train/validation เท่านั้น คะแนนในกราฟ tuning คือผล validation ไม่ใช่ test
  3. เลือกสูตรชนะต่อคู่ตาม best validation Macro F1, Accuracy, lower loss, trial order แล้วล็อก reference pair จาก 15 คู่ด้วย validation
  4. ฝึกจาก ImageNet weights ใหม่ 5 matched seeds ต่อคู่ เลือก checkpoint ด้วย validation แล้วประเมิน test ภายหลัง
  5. สรุป mean ± sample SD จาก seeds; paired tests join ด้วย seed ID และปรับ Holm แยก primary family 28 และ secondary family 30

ข้อจำกัด

  • ผลต่างระหว่าง seeds สะท้อนความแปรปรวนบน split เดียว ไม่แทนชุดข้อมูลใหม่
  • การทำ CAM เป็นเครื่องมือวินิจฉัย ไม่ยืนยันเหตุและผล
  • อ่านค่า W&B ตามสถานะจริงของแต่ละ run; การมีไฟล์ local ไม่ยืนยันว่า sync ขึ้น cloud
  • แนวทางผู้สอนและ PDF อ้างอิงไม่มีในโฟลเดอร์นี้ จึงยังยืนยันความสอดคล้องกับผู้สอนไม่ได้
